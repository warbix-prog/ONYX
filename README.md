# ONYX

**Application de streaming Android — Mobile + TV (Android TV / Chromecast)**

---

## Télécharger

Rendez-vous dans la section **[Releases](https://github.com/warbix-prog/ONYX/releases)** pour télécharger la dernière version de l'APK.

### Installation

1. Téléchargez le fichier `.apk` depuis les Releases
2. Sur votre appareil Android, autorisez l'installation depuis des sources inconnues (Paramètres → Sécurité)
3. Ouvrez le fichier APK pour installer l'application
4. Lancez ONYX et profitez !

> **Compatible** : Android 7+ (Mobile), Android TV, Chromecast avec Google TV

---

## Fonctionnalités

- Streaming en direct (TV françaises et internationales)
- Films et séries à la demande
- Interface optimisée Mobile et TV (télécommande)
- Qualité vidéo HD / Full HD
- Favoris et historique
- Mise à jour automatique des sources
